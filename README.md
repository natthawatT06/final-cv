# 📚 ระบบคลังข้อสอบ & แบบฝึกทบทวน (Exam Review Hub)

เว็บแอปพลิเคชันสำหรับทำแบบฝึกหัดข้อสอบและทบทวนบทเรียน 4 รายวิชา ดีไซน์เรียบหรูโทนสีขาว (Minimalist White) รองรับ Responsive 100% บนมือถือ แท็บเล็ต และคอมพิวเตอร์ พร้อมระบบสุ่มมีมให้กำลังใจตอนเปลี่ยนข้อ

---

## 🌟 จุดเด่นของระบบ

- **คัดกรองข้อซ้ำออกทั้งหมด:** รวมข้อสอบทั้ง 4 คอร์สจากเดิม 258 ข้อ คัดกรองข้อซ้ำเหลือ **196 ข้อคุณภาพ**
- **เฉลยแม่นยำ พร้อมคำอธิบาย:** มีเฉลยและแนวคิดประกอบทุกข้อ
- **ดีไซน์ขาว สบายตา (Clean Minimalist Design):** เน้นความเรียบง่าย สวยงาม ไม่รกสายตา ใช้งานได้จริง
- **Responsive 100%:** รองรับการใช้งานทั้งบนสมาร์ทโฟน แท็บเล็ต และหน้าจอคอมพิวเตอร์
- **2 โหมดการใช้งาน:**
  - 💡 **โหมดเฉลยทันที (Practice Mode):** คลิกเลือกตอบแล้วรู้ผลทันที (เขียว=ถูก, แดง=ผิด) พร้อมกล่องอธิบายแนวคิดใต้ข้อนั้น
  - ⏱️ **โหมดสอบจริง (Exam Mode):** ซ่อนเฉลยไว้ก่อน ทำเสร็จแล้วกดส่งตรวจเพื่อดูคะแนนรวมและข้อที่ทำผิด
- **ฟังก์ชันการทบทวน:**
  - 🗺️ แผนผังข้อสอบ (Question Grid) สำหรับกดกระโดดข้ามไปข้อที่ต้องการ
  - ❌ กรองเฉพาะข้อที่เคยตอบผิด เพื่อฝึกทำซ้ำจนชำนาญ
  - 🔀 สุ่มสลับข้อสอบ (Shuffle)
  - ⌨️ รองรับคีย์บอร์ดชอร์ตคัต (กด `1`, `2`, `3`, `4` เลือกช้อยส์ และลูกศร `←` / `→` เพื่อเปลี่ยนข้อ)
- **🎭 มีมสุ่มเพิ่มความสนุก (Meme Surprise):** ดึงรูปมีมจากโฟลเดอร์ `m/` โผล่มาสุ่มตำแหน่ง 3 วินาทีตอนกดถัดไป (มีปุ่มเปิด/ปิดได้ตามต้องการ)
